## Recent updates worth knowing

- **Refreshed repository pull requests page is generally available.** The redesigned PR list view is now on by default for all repositories. ([GitHub Changelog, Sep 21](https://github.blog/changelog/2026-09-21-refreshed-repository-pull-requests-page-generally-available))
- **More ways to request and configure Copilot code reviews.** New options make it easier to trigger and customize automated Copilot reviews on pull requests. ([GitHub Changelog, Sep 23](https://github.blog/changelog/2026-09-23-copilot-code-review-more-ways-to-request-and-configure-reviews))
- **Workflow execution protections in GitHub Actions are generally available.** Repositories can now enforce stricter controls over which workflows are allowed to run, reducing supply-chain risk. ([GitHub Changelog, Sep 17](https://github.blog/changelog/2026-09-17-workflow-execution-protections-in-github-actions-generally-available))
- **Control GitHub Actions cache access with `cache-mode`.** A new setting lets teams scope which workflows can read and write the Actions cache. ([GitHub Changelog, Sep 10](https://github.blog/changelog/2026-09-10-control-github-actions-cache-access-with-cache-mode))
- **Node 20 is no longer available in GitHub Actions.** Workflows and actions still pinned to Node 20 runtimes need to move to a supported version. ([GitHub Changelog, Sep 23](https://github.blog/changelog/2026-09-23-node-20-is-no-longer-available-in-github-actions))
